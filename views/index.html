🏛️ Architecture & Security Model

This full-stack application implements a modern dual-token authentication architecture:

  • Short-lived Access Token: Stored securely in JavaScript memory (never in localStorage to prevent XSS). Sent in HTTP Authorization: Bearer headers.
  • Long-lived Refresh Token: Stored in an HttpOnly, SameSite Cookie. Accessible only by the browser to request new Access Tokens via GET /refresh.
  • Silent Auto-Refresh: The API client automatically catches 401/403 expired token responses, issues a background refresh, and replays the original request transparently!
  • Role-Based Access Control: Enforced at the middleware level (verifyRoles) for User (2001), Editor (1984), and Admin (5150).
